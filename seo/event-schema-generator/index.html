Free Event Schema Generator

Create Event JSON-LD structured data for conferences, workshops, webinars and other events with dates, location and organizer information.

What is Event schema?

Event structured data describes an event, including its name, dates, location, organizer and event status. It helps search engines understand event information on a page.

How to generate Event JSON-LD

Enter the real event details shown on your page. Use the local date and time format required by Schema.org, generate the JSON-LD and add it to the event page.

Event SEO best practices

Keep start and end dates accurate. Use a real venue or valid virtual location, and update event status when the event is postponed, cancelled or completed.

FAQ

Can I use Event schema for a webinar?
Yes, where the page genuinely represents an event and the virtual event details are accurate.
Should I add an event that already ended?
Use event data that accurately reflects the event and its status rather than presenting an old event as upcoming.
