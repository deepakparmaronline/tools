What is a canonical tag?

A canonical link element tells search engines which URL is the preferred version of a page when multiple URL variants represent similar content.

How to check a canonical tag

Paste the HTML of the page, especially its head section. The checker finds canonical link elements and reports the URL values.

Canonical SEO best practices

Use one clear canonical URL where appropriate, keep it consistent with your preferred URL, avoid pointing canonicals to irrelevant pages and make sure important pages are not canonicalized away by mistake.

Common canonical mistakes

The most common issues are canonicals pointing to a different page entirely after a redesign, multiple conflicting canonical tags on one page, canonicals pointing to a non-indexable or noindexed URL, and simply forgetting to add one on pages that generate duplicate URL variants, such as filtered or sorted category pages.

FAQ

Does this fetch a live page?
No. It analyzes pasted HTML, so it works without an API and also works on staging or password-protected pages you can view source on.
Can a page have multiple canonical tags?
It can contain them in the markup, but multiple conflicting canonical tags are a real issue: search engines may pick one arbitrarily or ignore all of them, so a page should have exactly one canonical link element.
Should a canonical tag point to itself?
Yes, for most pages a self-referencing canonical, pointing to the page's own preferred URL, is standard practice and helps prevent duplicate content issues from tracking parameters or URL variants.
What happens if a page has no canonical tag at all?
Search engines will try to pick a canonical version on their own using other signals, such as internal links and sitemaps, which does not always match the URL you would have chosen.
