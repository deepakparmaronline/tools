What is an outbound link?

An outbound link is a link from your page to another website or hostname. An outbound link analyzer helps you review these links during technical and content SEO work.

How to analyze outbound links

Paste the HTML of a page and enter its base URL. The tool counts links and lists the selected links it finds.

Outbound link SEO best practices

Link to useful, trustworthy resources when they help the reader. Review broken destinations, irrelevant links and link attributes that should be sponsored or user-generated.
