What is a sitemap index?

A sitemap index is an XML file that points search engines to multiple sitemap files. It is useful for websites that maintain separate sitemaps for different content types or URL groups.

Why use a sitemap index builder?

Manually writing XML is easy to get wrong. This tool creates the XML structure for you and keeps the input focused on the sitemap URLs you actually want to publish.

When should you use one?

Use a sitemap index when your site has multiple sitemap files, such as posts, pages, products, images or separate sitemap files created by different systems. Keep each sitemap focused and make sure its URLs are accessible.

FAQ

What is a sitemap index file?
A sitemap index is an XML file that lists the locations of multiple sitemap files.
When should I use a sitemap index?
Use one when you manage multiple sitemap files, such as separate sitemaps for posts, products, images or large URL groups.
Does this tool submit the sitemap index to Google?
No. It only generates the XML in your browser. You publish it and submit its URL through your normal Search Console workflow.
