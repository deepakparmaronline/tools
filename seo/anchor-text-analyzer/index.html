Extract anchor text from links and see which phrases are repeated, unique or empty.

What is anchor text?

Anchor text is the visible text of a link. Descriptive anchor text gives users and search engines useful context about the linked page.

How to analyze anchor text

Paste HTML containing links. The tool counts anchor phrases and sorts them by frequency.

Anchor text SEO tips

Use natural, descriptive phrases that fit the sentence. Avoid forcing exact-match keywords into every internal link. A healthy internal linking pattern should help users first.
