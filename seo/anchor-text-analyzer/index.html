What is anchor text?

Anchor text is the visible text of a link. Descriptive anchor text gives users and search engines useful context about the linked page.

How to analyze anchor text

Paste HTML containing links. The tool counts anchor phrases and sorts them by frequency.

Anchor text SEO tips

Use natural, descriptive phrases that fit the sentence. Avoid forcing exact-match keywords into every internal link. A healthy internal linking pattern should help users first.

FAQ

What counts as an empty anchor?
An empty anchor is a link with no visible text, often an image link with no alt text or a link built from an icon alone. Empty anchors give search engines and screen reader users no context about the destination.
Is repeated anchor text always a problem?
Not always. Navigation links and buttons naturally repeat the same anchor site-wide. The concern is mainly repeated exact-match keyword anchors inside body content or backlinks, which can look manipulative.
Does this tool crawl my whole website?
No. It analyzes only the HTML you paste in, one page at a time, and does not make any external requests.
What should I do with the anchor list this tool produces?
Scan for anchors that repeat too often or say nothing useful, like click here, and rewrite them to be more descriptive of the destination page.
