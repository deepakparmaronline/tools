Label Search Console queries by likely search intent so you can review content and landing-page opportunities faster.

What is search intent?

Search intent is the reason behind a query. For SEO work, common groups include informational, commercial, transactional and navigational searches.

How this GSC intent classifier works

The tool uses clear word patterns such as question terms, comparison language, buying words and brand-like navigation terms. It does not claim to know a person's intent with certainty.

Why use GSC data?

Your Search Console queries show the searches that already produce impressions for your site. Classifying those queries can help you spot pages that are targeting the wrong intent or content gaps that deserve attention.

Use the result as a review layer

Intent classification is a shortcut, not a replacement for reading the query and checking the search results. If a keyword looks ambiguous, review it manually before changing a page.
