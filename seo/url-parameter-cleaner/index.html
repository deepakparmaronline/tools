Free URL Parameter Cleaner

Remove common tracking parameters from URLs and create cleaner links for sharing, documents and SEO work. Everything runs locally in your browser.

What is a URL parameter?

A URL parameter is a key-value pair added after a question mark in a web address. Parameters can carry useful information, but many links also contain campaign tracking values that make URLs long and messy.

Why clean tracking URLs?

Cleaner URLs are easier to read, copy, paste and share. Removing tracking values can also make a link safer to reuse in places where campaign attribution is not needed.

Use care with important parameters

Not every parameter is a tracking parameter. Product filters, search terms, session controls and other application values can affect the page. This tool only removes the parameters you select.

FAQ

What does a URL parameter cleaner do?
It removes selected query-string parameters from a URL while keeping the main page address and any parameters you choose to retain.
Which URL parameters are commonly removed?
Common tracking parameters include utm_source, utm_medium, utm_campaign, utm_term, utm_content, gclid, fbclid and msclkid.
Does cleaning a URL change the destination page?
It can. Some parameters are required by a website. Only remove parameters you know are used for tracking or are otherwise unnecessary.
