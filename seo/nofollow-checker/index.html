What is nofollow?

Nofollow is a link-related robots directive. When used as a page-level robots directive, it tells compliant crawlers not to follow links on that page.

How to check nofollow

Paste the robots meta content and run the checker. It reports whether the nofollow token is present.

Technical SEO note

Use page-level nofollow only when there is a clear reason. Link-level rel attributes are often more precise when the instruction applies to selected links rather than an entire page.
