Create WebPage JSON-LD structured data for pages such as service, about, contact and general website pages.

What is WebPage schema?

WebPage structured data describes a web page and can provide search engines with useful properties such as its name, URL, description, language and publisher.

How to create WebPage JSON-LD

Enter information that matches the page. Generate the code and add it to the HTML of the page. Use a more specific WebPage subtype when it genuinely fits the content.

WebPage schema best practices

Keep the name and description consistent with visible page content. Use the canonical URL where appropriate and avoid adding properties that are not true.

FAQ

Is WebPage schema the same as Organization schema?
No. WebPage describes the page; Organization describes the organization represented by the site or content.
Can service pages use WebPage schema?
Yes, when the page is a web page and the structured data accurately describes it. More specific types may also apply.
