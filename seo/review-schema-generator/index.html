What is Review schema?

Review structured data describes a review and its subject, rating, author and review text. It should represent genuine content that is visible and eligible for structured-data use.

How to generate Review JSON-LD

Enter the review exactly as it appears on the page. Add the real reviewer name, rating and item information, then generate the JSON-LD.

Review schema best practices

Never invent reviews, ratings or reviewers. Follow the structured-data rules for the type of content you are marking up and keep the markup consistent with visible content.

FAQ

Can I create fake review schema?
No. Only use genuine review content. Misleading structured data can make a page ineligible for search features.
What rating scale should I use?
Use the scale that the actual review system uses and provide valid numeric values.
