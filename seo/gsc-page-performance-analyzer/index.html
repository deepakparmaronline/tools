Free GSC Page Performance Analyzer

Aggregate Search Console query data by URL to see page-level impressions, clicks and weighted CTR.

Why analyze GSC performance by page?

Query-level reports can hide how an individual URL performs across many searches. Aggregating the data by page gives you a clearer view of which URLs earn visibility and clicks.

What the analyzer calculates

The tool adds clicks and impressions for each page and calculates a weighted CTR from those totals. This avoids treating a tiny query and a large query as equal.

How to use the report

Sort through the pages with high impressions but modest CTR, strong click volume, or large visibility changes in your own reporting workflow. Then inspect the page itself before deciding what to change.

Why this is different from a live audit

This tool analyzes Search Console performance data. It does not crawl your URLs, check page speed or inspect your current HTML. Use a technical crawler for those jobs.

FAQ

Can I analyze an exported GSC report?
Yes. Paste a CSV containing Page, Clicks and Impressions data.
Is page CTR averaged?
No. The page CTR is based on total clicks divided by total impressions.
