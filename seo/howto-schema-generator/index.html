What is HowTo schema?

HowTo structured data describes a page that teaches someone how to complete a task through ordered steps. The markup helps machines understand the instructions already published on the page.

How to generate HowTo JSON-LD

Add the actual step names and instructions from your page. Generate the JSON-LD and place it in the page head or body. Keep the structured data consistent with the visible instructions.

HowTo schema tips

Use clear step names, useful instructions and the correct order. Do not create HowTo markup for content that is not a genuine step-by-step guide.
