What is a URL parameter?

A URL parameter is a key-value pair added to a URL after a question mark. Parameters can pass campaign, filter, sort, search or other information to a page.

How to generate a URL with parameters

Enter the base URL, then add one key-value pair per line, such as utm_source=google. The generator encodes the values and creates the finished URL.

URL parameter SEO best practices

Use parameters only when they have a clear purpose. Tracking and filter parameters can create many URL variants, so review canonical URLs, internal links and crawl controls when parameters create duplicate pages.

Frequently asked questions

Can I use this as a UTM URL builder?
Yes. Add UTM parameters such as utm_source, utm_medium and utm_campaign.
Are parameter URLs bad for SEO?
No. Their impact depends on how the parameters are used and how many URL variants they create.
