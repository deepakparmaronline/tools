What is a URL parameter?

A URL parameter is a value added to a URL after a question mark. Parameters can pass campaign, filter, sort, search or other information to a page.

How to build URL parameters

Enter a base URL with your parameters in the format key=value&key2=value2. The tool encodes the query values and gives you a URL you can copy.

URL parameter best practices for SEO

Use parameters only when they have a clear purpose. Uncontrolled filters and tracking parameters can create many URL variations, so review canonical tags and crawl rules when parameters create duplicate pages.

Frequently asked questions

Can I use this as a UTM URL builder?
Yes. You can enter UTM names and values as regular URL parameters.
Does a URL parameter affect SEO?
It can. Search engines may treat parameter URLs as separate URL variants, depending on the page and signals.
