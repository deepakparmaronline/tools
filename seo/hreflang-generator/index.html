What is a hreflang tag?

Hreflang is an international SEO signal used to tell search engines about alternate language or regional versions of a page. It can help search engines serve a more suitable URL to users in different markets.

How to use this hreflang generator

Add the canonical URL for each language or region and enter its hreflang value, such as en, en-us, en-gb, fr-fr or de-de. The tool creates standard link elements that you can place in the HTML head of your pages.

Hreflang best practices

Use valid language and regional codes, keep the URLs consistent, include an x-default version when it makes sense, and make the annotations reciprocal across the alternate pages. Hreflang does not replace canonical tags.

FAQ

What is a hreflang tag?
A hreflang annotation tells search engines which language and regional version of a page is intended for a particular audience.
Can hreflang use language and country codes?
Yes. Common values include en, en-us, en-gb, fr and de-de. Language uses ISO 639-1 codes and region uses ISO 3166-1 Alpha-2 codes.
Should hreflang pages reference each other?
Hreflang annotations should normally be reciprocal. Each alternate page should identify the other relevant language or regional versions, including itself.
