Free Breadcrumb Schema Generator

Create BreadcrumbList JSON-LD structured data for website navigation. Add each breadcrumb name and URL and generate clean schema markup.

What is BreadcrumbList schema?

Breadcrumb structured data tells search engines about the hierarchy represented by breadcrumbs on a page. It can help machines connect a page with its place in a site structure.

How to create breadcrumb schema

Enter each breadcrumb in order, starting with the highest-level page and ending with the current page. Use the same labels and URLs visitors see on the page.

Breadcrumb SEO best practices

Keep breadcrumb labels short and useful. Use canonical page URLs and make sure the breadcrumb trail matches the site's real navigation.

FAQ

How many breadcrumbs can I add?
Add as many levels as your page actually has. This generator supports up to six.
Does breadcrumb schema create breadcrumbs by itself?
No. It describes breadcrumbs that already exist on the page.
