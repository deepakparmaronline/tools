What is keyword cannibalization?

Keyword cannibalization is when multiple pages on the same website target the same search intent and compete for visibility. Seeing two URLs for one query is not automatically a problem. Some queries naturally have several relevant pages, so the useful question is whether the overlap is hurting your site's ability to rank the right page.

How this GSC cannibalization checker works

Paste a Google Search Console export containing both Query and Page data. The tool groups rows by search query, combines impressions for each URL, measures how much visibility is concentrated on the leading URL and looks at position spread. It then labels candidates as High, Medium or Low priority.

What counts as a stronger cannibalization signal?

A query with several URLs, a large share of impressions spread across competing pages, or a wide difference in ranking positions deserves more attention than a query with two pages where one page clearly dominates. These are review signals, not proof of a ranking problem.

What should you do after finding a candidate?

Compare the search intent, page purpose, titles, headings, content overlap, internal links and actual search results. If two pages serve the same intent, consider consolidating them. If they serve different intents, improve their differentiation instead of merging them just because both appear in Search Console.

How to export the right GSC data

In Google Search Console, use the Performance report and include both Query and Page dimensions before exporting. The checker needs that query-to-URL relationship. A query-only export cannot identify which URLs compete for the same search.

FAQ

Does two URLs for one keyword prove cannibalization?
No. It is only a signal. Review intent and the actual SERP before changing pages.
Can I use this without connecting Google Search Console?
Yes. Export your GSC data and paste it here. The analysis runs in your browser.
What columns do I need?
Query and Page are required. Clicks, Impressions and Position are recommended because they make the prioritization more useful.
Should I redirect every competing URL?
No. Redirect only when the pages overlap in purpose and consolidation is the right content decision.
