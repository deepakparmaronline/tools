What are Open Graph tags?

Open Graph tags are HTML metadata that describe a page when its URL is shared on platforms that read the Open Graph protocol. They help control the title, description, image and URL shown in a social preview.

How to use this OG tag generator

Add your page information, choose the content type and generate the code. Paste the tags inside the HTML head of the page you want to share.

Open Graph tags worth adding

The core tags are og:title, og:description, og:url, og:type and og:image. Use an image that represents the page and a URL that matches the preferred page address.

Frequently asked questions

Is Open Graph the same as SEO metadata?
They overlap, but Open Graph is mainly for social sharing previews rather than search ranking snippets.
Where should OG tags go?
Place them in the HTML head of the page.
Does og:image need an absolute URL?
Use a complete HTTPS image URL so crawlers and social platforms can fetch it reliably.
