Free SEO Migration URL Mapper

Compare old and new URL lists and get path-based destination suggestions for a migration redirect map. Everything runs in your browser.

What is an SEO migration URL map?

An SEO migration URL map pairs each old URL with its intended final destination. It is a practical planning file for redesigns, replatforming, URL structure changes and domain migrations.

How this URL mapper works

The tool compares URL path segments and shared words between your old and new URL lists. It suggests the closest new URL and gives a simple similarity score. This is intentionally a review aid, not an automatic redirect decision system.

Always review migration mappings

A URL that looks similar is not always the correct destination. Google recommends preparing a URL mapping when URLs change and using server-side permanent redirects where possible. Review every suggested mapping before launch.

FAQ

What is an SEO migration URL map?
It is a list that maps an old URL to its intended new destination during a site migration, redesign or URL structure change.
Can this tool automatically choose the correct redirect?
No. It creates suggestions using URL path similarity. Every suggested destination should be manually reviewed before redirects are implemented.
Why is URL mapping important during a migration?
A URL map helps teams plan redirects and preserve the relationship between old and new pages. Google recommends preparing URL mapping when URLs change during a site move.
