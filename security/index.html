Security

Last updated: August 2026

Our approach

Tool Box Kart is built to keep as little of your data as possible in the first place. Less data held means less risk if anything ever goes wrong.

Your files stay on your device

Most tools on this site, including image and file converters, run entirely in your browser using JavaScript. Your files are processed on your own device and are never uploaded to our server.

Encrypted connection

The whole site is served over HTTPS. Any data that does travel between your browser and our server, such as a page request, is encrypted in transit.

No accounts, no stored passwords

Tool Box Kart does not use signups or logins. Since there are no user accounts, there are no passwords stored on our end that could be exposed.

Third-party services

We load Google Fonts to display text on the site. Loading a font makes a request to Google's servers, which is standard practice on most websites. We do not embed third-party ad scripts or trackers on this site.

Reporting a security issue

If you find a security problem on Tool Box Kart, please tell us before sharing it publicly, so we can fix it first. Email details of the issue to security@toolboxkart.tech. We will look into every report we receive.
