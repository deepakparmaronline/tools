# Help Scout guide

Canonical: https://toolboxkart.tech/helpscout/

**Short answer:** Help Scout is customer support software built around shared conversations, a team inbox and a knowledge base. It suits teams that want customer history and help content close to email support. Check the Free plan contact limit, paid seat price and AI usage cost before you move a whole support operation.

## What is Help Scout?

Help Scout gives a support team one place to read customer messages, assign ownership, add private notes and keep the conversation history together. The product is more than a shared email address. It connects the Inbox with Docs, Beacon, workflows, reporting and customer context. The official product overview describes a support workspace for teams that want a personal customer experience without making every request feel like a formal ticket.

The main model is conversation-first. Agents work from shared inboxes and can use tags, saved replies, views and workflows to keep work moving. Teams can add a Docs site for public help articles and use Beacon to show answers or a contact option on their website.

## How the workspace fits together

### Shared Inbox and customer context

The Inbox brings customer messages into a shared queue. Teammates can assign a conversation, add an internal note, use a saved reply and see past customer activity. This works well when several people answer the same support address and need to avoid duplicate replies. Separate inboxes can help when billing, product support and sales questions need different owners.

### Docs and Beacon

Docs is the hosted knowledge base. It gives customers a place to find setup steps, product answers and common fixes before they contact support. Beacon is the website widget that can surface Docs and offer a contact route. A useful Beacon needs current articles and a clear escalation path. A widget with old help content can make the support experience worse, even if the inbox itself is well managed.

### Workflows, SLAs and reporting

Workflows can apply repeatable actions when a conversation matches conditions. Teams can use them for tagging, assignment, status changes and notifications. Paid plans list different workflow and SLA allowances, so check the plan table before designing a large rule set. Help Scout release notes also describe updates to Topics, Company Profiles, SMS, the Customer Portal and MCP during 2026. Availability can depend on plan and rollout.

### AI assistance and the Envoy add-on

The pricing page lists an AI Inbox assistant and AI drafting features on paid plans. It also lists Envoy as an AI agent add-on priced by resolution. The public price shown for Envoy is US$0.75 per resolution, which is a different meter from a seat or a monthly contact allowance. Help Scout setup documentation uses the Scout name for the agent setup flow. Check the current in-app label, plan access and resolution definition before estimating AI spend.

## Limits to check before you buy

The Free plan is not an unlimited shared inbox. It is capped at five users, one inbox, one Docs site and 100 contacts per month. If the contact allowance is reached, the team may need to wait for the next cycle or move to a paid plan before replying. Paid plans add more inboxes, Docs sites, workflows and service controls, but the price is per user.

Migration also needs a plan. Help Scout has an official import path for several help desks, including Freshdesk and Zendesk. The import guide says that users and inbox settings, knowledge base articles, saved replies, rules, automations, custom fields and custom statuses are not all moved as native objects. Treat the import as a way to bring selected conversation history, not as a full copy of the old system.

## Who should use Help Scout?

Shortlist Help Scout when a small or mid-sized team wants shared ownership of email conversations, a help centre and a website contact widget. It can also suit a larger team that is comfortable with its conversation model and has checked the higher-plan controls. Compare another product if your process depends on deep ticket taxonomies, complex routing, ecommerce order context or a strict self-hosted knowledge base requirement.
