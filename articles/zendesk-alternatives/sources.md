# Zendesk alternatives: evidence ledger

Prices are volatile. Current Zendesk, Freshdesk, Help Scout, Zoho Desk, Intercom, Front and Gorgias sources were rechecked October 29, 2026. HubSpot and Salesforce price notes retain the October 27, 2026 check date.

## Zendesk

- Product: https://www.zendesk.com/
- Pricing: https://www.zendesk.com/pricing/ — Support Team US$19, Suite Team US$55 and Suite Professional US$115 per agent/month billed yearly, checked October 29, 2026.
- Export guide: https://support.zendesk.com/hc/en-us/articles/4408886165402-Exporting-ticket-user-or-organization-data-from-your-account — JSON, CSV and XML export options; the article says export access is not enabled by default and account export tools are not available on Team plans, though the REST API can export data.
- Migration: https://support.zendesk.com/hc/en-us/articles/6696005837082-How-can-I-migrate-information-from-another-platform-into-Zendesk — API import guidance; some ticket metrics are not imported through the documented ticket import path.
- Product updates: https://support.zendesk.com/hc/en-us/sections/4405298877338-What-s-new-in-Zendesk — official monthly update index. No specific release claim is made.

## Freshdesk

- Product: https://www.freshworks.com/freshdesk/
- Pricing: https://www.freshworks.com/freshdesk/pricing/ — Growth US$19, Pro US$55 and Enterprise US$89 per agent/month billed annually; first 500 Freddy AI Agent sessions listed as included once per account, additional sessions US$49/100, Copilot US$29/agent/month on Pro and Enterprise. Checked October 29, 2026.
- Plan and Free Program help: https://support.freshdesk.com/support/solutions/articles/50000011778-understanding-freshdesk-pricing-plans — distinguishes email-first Freshdesk from multichannel Freshdesk Omni; trial and Free Program rules.
- Ticket export: https://support.freshdesk.com/support/solutions/articles/225158 — modified February 16, 2026; explains ticket export options and limits.
- Account export: https://support.freshdesk.com/support/solutions/articles/237405-how-can-i-export-tickets-including-the-content-of-the-ticket- — broader ticket-content and account export guidance.
- API: https://developers.freshdesk.com/api/ — official API reference.
- Quarterly customer-service update: https://www.freshworks.com/freshdesk/webinars/whats-new-cs-2026/ — on-demand session dated July 16, 2026 about Freshdesk and Freshdesk Omni updates. It is a product update session, not a release-by-release changelog; the article makes no claim about a specific new release.

## Alternatives

- Help Scout pricing: https://www.helpscout.com/pricing/ — Free for up to five users with one inbox and one Docs site; paid plans displayed from US$25/user/month; Envoy at US$0.75/resolution. Checked October 29, 2026.
- Help Scout docs: https://docs.helpscout.com/ — official setup, inbox, workflow, billing and Docs help.
- Zoho Desk pricing: https://www.zoho.com/desk/pricing.html — Free Edition for three users and a 15-day trial; the page has a region/currency selector and the page view used displayed INR prices. No US-dollar paid starting price was quoted. Checked October 29, 2026.
- Zoho Desk help: https://help.zoho.com/portal/en/kb/desk — official support documentation.
- Intercom pricing: https://www.intercom.com/pricing — Essential displayed at US$19/seat/month for new customers in the annual-billing view, with US$29 shown as the prior rate; Advanced US$85, Expert US$132 and Fin US$0.99 per outcome. Promotions and usage terms can change. Checked October 29, 2026.
- Intercom help: https://www.intercom.com/help/en/ — official help center. Product updates collection: https://www.intercom.com/help/en/collections/198493-product-updates (direct access was not available in the browser tool, so no release-specific claim is made).
- Front pricing: https://front.com/pricing/ — Starter US$25, Professional US$65 and Enterprise US$105 per seat/month billed annually. Checked October 29, 2026.
- Front help: https://help.front.com/ — official setup, inbox, rules and integration documentation.
- Gorgias pricing: https://www.gorgias.com/pricing — ticket-volume pricing from 50 to 5,000 tickets/month, not per agent; AI Agent is charged when it resolves a conversation; Voice and SMS are usage-based add-ons. Exact plan prices were not exposed in the page text view, so no exact starting amount is quoted. Checked October 29, 2026.
- Gorgias help: https://docs.gorgias.com/ — official help center and developer documentation.
- LiveAgent product/pricing: https://www.liveagent.com/ and https://www.liveagent.com/pricing/ — official pricing page advertises a 30-day trial, no setup fee and no credit card requirement; plan selector is used for current tier prices. Checked October 29, 2026.
- LiveAgent support and updates: https://support.liveagent.com/ — official support portal includes Important Updates & Changes and a developer changelog link.
- HubSpot Service Hub pricing: https://www.hubspot.com/pricing/service — prior check October 27, 2026; free tools for up to two users and seat-based paid plans. Recheck before relying on the current price.
- Salesforce Service Cloud pricing: https://www.salesforce.com/service/pricing/ — prior check October 27, 2026; multiple editions. Recheck before relying on the current price.
