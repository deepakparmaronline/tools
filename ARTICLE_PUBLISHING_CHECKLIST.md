# ToolBox Kart Article Publishing Checklist

## 📋 Overview
All articles now have **centralized shared layout automation**. Once you push an article to GitHub, the system automatically:
- Injects shared header/footer navigation
- Adds breadcrumbs (Home → Category → Article Title)
- Adds author byline (photo + name + bio + social links) below the title
- Adds author bio box before the "sources" section
- Generates category listing pages dynamically

**You do NOT need to manually add any of these elements.** The system handles it all via JavaScript injection on page load.

---

## 🏗️ Architecture Overview

### Core Files & Their Roles

| File | Purpose | Location |
|------|---------|----------|
| **assets/site.js** | Master shared layout engine - injects nav, footer, breadcrumbs, author blocks | `/assets/site.js` |
| **assets/content-index.json** | Searchable index of all published articles | Auto-generated by workflow |
| **assets/manifest.php** | Navigation menu structure (categories & tools) | `/assets/manifest.php` |
| **.github/workflows/ensure-shared-layout.yml** | GitHub Actions automation that runs on every push | `.github/workflows/ensure-shared-layout.yml` |
| **scripts/build-content-index.py** | Builds the article index from canonical URLs | `scripts/` |
| **scripts/build-category-indexes.py** | Updates category listing pages with latest articles | `scripts/` |
| **scripts/ensure-shared-layout.py** | Backfills old articles and injects site.js script tag | `scripts/` |

## 🎯 What Happens Automatically When You Push

### 1️⃣ **GitHub Actions Workflow Triggers**
Every time you `git push` to `main`, this workflow runs automatically:

**Steps:**
1. Checks out your code
2. Runs `build-content-index.py`
   - Scans all article directories for canonical URLs
   - Extracts article title, description, and category
   - Writes to `assets/content-index.json`
3. Runs `build-category-indexes.py`
   - Updates category pages (seo-guide, tech, tools-guide, explainers)
   - Populates them with latest articles from content-index.json
4. Runs `ensure-shared-layout.py`
   - Injects `<script src="/assets/site.js" defer></script>` into every `index.html` file if missing
5. **Commits these generated files back to GitHub** if there are changes

### 2️⃣ **Runtime Behavior (When User Visits Page)**
When a visitor loads any article on your site:

1. **site.js loads** (in `<body>` footer)
2. **Navigation renders** at the top
   - Sticky dark navbar with categories and links
3. **Breadcrumbs inject** at the top of `<main>`
   - Format: "Home / [Category] / [Article Title]"
4. **Author byline injects** below the `<h1>` title
   - Shows: [Photo] By [Name] · [Bio] [LinkedIn] [YouTube]
5. **Author box injects** before the "sources" section
   - Full author bio with links to LinkedIn and YouTube
6. **Footer renders** at the bottom
   - Links to all categories, legal pages, tools
   - Copyright notice

## ✅ Article File Structure Requirements

For the automation to work correctly, your article **index.html must have:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Your Article Title | Tool Box Kart</title>
  <meta name="description" content="Your article description">
  <link rel="canonical" href="https://toolboxkart.tech/[category]/[slug]/">
  <!-- Other metadata -->
</head>
<body>
  <main>
    <h1>Your Article Title</h1>
    
    <!-- Article content here -->
    
    <!-- IMPORTANT: Section where author box will inject -->
    <section class="sources">
      <!-- Your sources/references go here -->
    </section>
  </main>
  
  <!-- REQUIRED: Script tag (automatically injected if missing) -->
  <script src="/assets/site.js" defer></script>
</body>
</html>
```

### Critical Elements:
- ✅ `<main>` tag wrapping all content
- ✅ `<h1>` tag with article title (first line under main)
- ✅ `<link rel="canonical" href="...">` in head (used to extract article metadata)
- ✅ `<section class="sources">` or `<div class="sources">` before closing main (author box injects here)
- ✅ `<script src="/assets/site.js" defer></script>` in body footer (auto-injected if missing)

## ❓ Common Issues & Fixes

### Issue: Author box/byline not appearing
**Solution:** 
- Ensure `<section class="sources">` exists in article
- Ensure `<h1>` is inside `<main>`
- Check browser console for JS errors
- Hard refresh (Ctrl+Shift+R) to clear cache

### Issue: Breadcrumbs not showing
**Solution:**
- Verify article is in `/seo-guide/`, `/tech/`, `/tools-guide/`, or `/explainers/`
- Check that `<h1>` exists and has text content
- Hard refresh browser

### Issue: Article not appearing on category page
**Solution:**
- Check canonical URL format
- Ensure article is in correct directory
- Verify workflow ran successfully (GitHub Actions)
- Check `assets/content-index.json` has your article

### Issue: Site.js not loading on Hostinger
**Solution:**
- Click "Redeploy" on Hostinger Git Integration
- Wait 2-3 minutes for deployment
- Hard refresh (Ctrl+Shift+R)
- Check browser Network tab - site.js should show 200 status
